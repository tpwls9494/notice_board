## 실제 이미지 표시 복원

후속 요청에 따라 현재 홈의 대표 글·소식 목록은 image_url이 있으면 이미지를 표시한다. 이미지가 없거나 로딩에 실패하면 이미지 요소와 전용 열을 제거해 제목·설명을 전체 폭으로 배치한다. 공통 장식 이미지를 대신 넣지 않는다. 이미지 URL이 바뀌면 실패 상태도 초기화된다. 상세의 본문 이미지 처리는 변경하지 않았다.

신규 HomeStoryMedia 컴포넌트를 사용한다. 대표 이미지는 즉시, 목록 이미지는 지연 로딩하며 referrerPolicy=no-referrer를 사용한다. 이미지를 누르는 중복 링크는 추가하지 않았다.

검증: 빌드 통과. 테스트 브라우저에서만 이미지 URL을 주입하여 유효·누락·실패 × 375/1280px × light/dark 12가지 상태 확인. 누락·실패 시 텍스트가 전체 폭으로 복원되고 문서 가로 넘침이 없는지 검사했다. 실제 DB·기사 이미지는 변경하지 않았다. 처음 검사에서 CORS 사전 요청을 모킹한 문제가 있어 GET만 대체하도록 검사 도구를 수정한 뒤 통과했다.

기록: ../.local-preview/editorial-preview-20260909/home-image-results.json. home-image-fixture-*.png는 렌더링 검사용 이미지이며 실제 기사 이미지나 생성 결과물이 아니다. 클로드 초안에는 아직 이미지가 없다.

## 후속 조정 — 사용자 피드백 반영

전체 너비 대표 글과 하단 커뮤니티 배치는 채택하지 않았다. 현재 로컬은 기존 운영 구조에 가까운 **왼쪽 소식 / 오른쪽 340px 커뮤니티**로 복원했다. 아래 최초 변경 기록은 이전 시안의 기록이다.

- 대표 글은 왼쪽에서만 강조하고 제목 크기·여백을 줄였다.
- 다른 소식은 왼쪽 단일 목록으로 표시한다. 대표 중복 제거·공통 장식 이미지 제거·불필요한 바로가기 제거는 유지한다.
- 커뮤니티는 빈 경우에도 짧은 상태 안내와 글쓰기 링크를 표시해 위치를 유지한다. 가짜 글은 추가하지 않았다.
- 모바일에서는 소식 다음 커뮤니티가 세로로 배치된다. 라운지 메뉴 정리와 기존 주소 보존은 유지한다.
- 빌드 및 선택 로직 테스트 5개 통과. 실제 로컬 API로 375/1280px × light/dark 확인: 데스크톱 좌우 정렬·오른쪽 340px·모바일 세로 배치·가로 넘침 없음·대표 글 및 라운지 경로 접근 통과.
- 새 증거: ../.local-preview/editorial-preview-20260909/home-columns-results.json 및 home-columns-375/1280-light/dark.png. 커뮤니티에 글이 채워진 시각 검사는 포함하지 않는다.

## 최초 시안 기록 — 현재 배치 아님

- 대표 글 1개를 별도 영역으로 분리하고 제목·소개·출처 중심으로 표시한다. 공통 코드 모양 장식 이미지, 번호 순위, 중복된 대형 바로가기 카드를 홈에서 제거했다.
- 대표 선택은 조회된 공개 글 중 is_featured 우선, 없으면 본문이 있는 글, 없으면 첫 글이다. 별도 선정 관리 기능을 만들거나 모든 자동 선정을 ‘편집자 추천’이라고 표시하지 않았다.
- 주목할 소식 조회가 비어 있으면 최신 목록으로 돌아간다. 조회 실패와 빈 목록을 구분한다.
- 대표 글을 제외한 소식 최대 4개를 데스크톱 2열·모바일 1열로 표시한다. 대표 글은 중복 노출하지 않는다.
- 커뮤니티 글이 있을 때 ‘사람들이 나누는 경험과 질문’을 하단에 표시한다. 기존 인기 정렬을 사용하며 운영자 수동 선별을 구현한 것은 아니다. 글이 없으면 빈 카드·글쓰기 유도 영역을 만들지 않는다. 오류는 별도로 알린다.
- 라운지는 상단 PC/모바일 메뉴와 홈 홍보에서 제거했다. /lounge 및 기존 게시물·작성 기능은 삭제하지 않았다. 커뮤니티에 ‘라운지 글 모아보기’ 보조 링크로 접근 경로를 남겼다. 데이터 이동·삭제는 없다.
- 기존 날짜·활동 요약은 유지하고 새 통계나 메뉴를 추가하지 않았다.
