## 목표와 독자

AI에 어느 정도 관심이 있는 개발자·일반 사용자가 최신 소식과 기발한 사용법을 발견하고, 변화의 의미를 이해하고, 자기 경험을 나누는 곳을 만든다. 운영자도 독자와 함께 배운다.

기술적으로 신기해도 사용이나 이해와 연결되지 않는 소재를 억지로 고르지 않는다. 반대로 직접 설치할 수 없다는 이유만으로 의미 있는 뉴스를 모두 제외하지 않는다.

근거: [국내외 50곳 비교](AI_CONTENT_BENCHMARK_50_20260909.md). 지속 적용 기준은 [EDITORIAL_POLICY.md](EDITORIAL_POLICY.md)가 담당한다. 비교 보고서는 조사 당시 기록으로 보존한다.

## 제작 흐름

후보 발견 → 동일 발표 중복 정리 → 원출처·사용 조건 확인 → 독자 질문 선정 → 글 역할 선택 → 초안 → 사실 및 읽을 가치 검토 → 승인된 범위에 등록·발행.

AI는 수집·대조·초안을 돕는다. 운영자가 소재와 공개 여부를 판단한다. 유료 모델이나 외부 계정을 쓰는 실험은 사전에 목적·비용·데이터 범위를 알린다. Fable 검토는 사용자가 전달하는 기존 방식을 유지한다.

- [x] 운영자가 초안 방향을 확인하고 로컬 구현 진행에 동의.

이미지는 추가하지 않았다. 확인한 공식 발표의 주요 시각 자료는 성능표·과학 연구 이미지이고, 요금제 도움말에는 제품 사용 화면이 없었다. 이 글의 작업 예시를 보여주는 적절한 실제 화면과 재사용 근거를 확보하지 못했으므로 이미지 작업은 미완료·보류로 남긴다. 장식 이미지나 가짜 실행 화면으로 대체하지 않는다. 원고 마감과 이미지 확보를 같은 완료 상태로 보고하지 않는다.

로컬 반영 전 본문 사본: ../.local-preview/editorial-preview-20260909/claude-before-final.json. 반영 후 본문 SHA-256: 8e51099740b3596264214fdc665c13c050ff4259ffb78d4fcc8762b7f33149f9. 원고와 DB 일치 및 모바일·명암 모드 검사는 claude-final-reader.json에 기록한다. 초기 읽기 검사에서 원고 경로를 잘못 지정한 오류를 수정한 뒤 재실행했다.

운영 공개 승인·운영 배포·유료 API 호출·Fable 직접 호출은 하지 않았다. 이미지 없이 이 해설을 공개할지, 실제 사용 화면을 확보한 뒤 공개할지는 별도 결정이다.

초안은 로컬 Markdown 파일로 보존하고, 별도로 만든 로컬 미리보기 DB에만 게시했다. 운영 서버 검토함 등록과 공개 발행은 하지 않았다. 독자의 질문에 답하는 해설이며 직접 사용 후기나 모델 비교 실험이 아니다.

### 2. 원고에 필요한 본문·발행 규칙 — 로컬 구현 완료

운영 소식 발행 코드는 아직 모든 content_kind에 try_this를 요구한다. 로컬 변경에서는 release/research의 실습은 선택으로 바꾸고 workflow는 필수로 유지했다. 본문 또는 기존 활용 포인트, 출처·검증 수준은 계속 검사한다. 임의 DB 갱신으로 공개 검사를 우회하지 않았다.

동의받은 범위에서 다음을 구현했다.

- [x] 소식·연구 해설에는 실습 절차를 요구하지 않는 관리자 발행 검토 기준.
- [x] 선택적 Markdown body 컬럼과 소제목·표·이미지·인용 렌더링. body가 없는 기존 글은 그대로 표시.
- [x] 검토함의 본문 편집·미리보기·저장.
- [x] 기존 댓글·대댓글·후기·원문 링크 유지.
- [x] 로컬 미리보기 및 기존 글 회귀 확인.
- [ ] 사용자가 실제 로컬 화면 확인 후 운영 배포 범위 결정.

새 body가 있는 수집 글은 검토함으로 보낸다. 기존 자동 수집의 공개 조건은 확대하지 않았다. 상세 결과와 실행 주소는 [로컬 검증 기록](EDITORIAL_BODY_LOCAL_20260909.md)에 남겼다.

새 상단 탭·새 댓글 분류·저장·뉴스레터·알림·자동 발행은 여기 포함하지 않는다.

### 3. 콘텐츠가 쌓인 뒤 이어 읽기

관련 글이 실제로 생겼을 때만 소식→해설→활용→경험을 연결한다. 메인 글은 그 자체로 완결하고, 기술 블로그에는 깊은 구현 기록을 선택적으로 연결한다. 관련 없는 추천과 빈 영역을 미리 늘리지 않는다.

### 4. 재방문 확인

내부 다음 글 읽기, 7일 내 재방문, 의미 있는 질문·경험을 확인하는 측정안을 별도로 제안한다. 외부 원문 클릭을 자동으로 실패라고 판단하지 않는다. 아직 이 지표를 수집하거나 측정 기능을 추가하지 않았다.
