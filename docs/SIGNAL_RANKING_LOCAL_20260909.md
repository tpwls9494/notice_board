# 홈 최신·인기·지금 뜨는 — 로컬 구현

2026-09-09. 운영 미반영. 확인: http://localhost:5173/

## 후속 화면 간소화

사용자 요청으로 현재 홈에는 **최신·인기 두 전환만** 표시한다. 지금 뜨는 전환과 전용 주기 조회, 계산식·참여자 수·최소 인원 안내 문구를 제거했다. 빈 인기 목록은 ‘인기 글이 아직 없어요.’로 표시한다. 기존 추천·댓글 총수는 유지한다.

인기 계산과 최소 참여 조건은 내부적으로 유지한다. 아래 최근 6시간 API 계산 설명은 기존 구현 기록이며 현재 홈에서 호출하지 않는다. API 제거·반응 데이터 삭제·운영 변경은 하지 않았다.

## 기준

- 최신: 사이트 published_at 내림차순. 원문 공개일이나 대표 지정 여부가 최신 순서를 바꾸지 않는다. 동률은 created_at, id 순서다.
- 인기: 현재 유효한 누적 추천 ×2 + 서로 다른 댓글 작성 계정 수.
- 지금 뜨는: 최근 6시간에 생성된 유효 추천 ×2 + 해당 시간에 공개 댓글·대댓글을 작성한 서로 다른 계정 수. 게시물 자체의 나이로 제한하지 않는다.
- 인기·지금 뜨는 모두 추천 계정과 댓글 계정의 합집합이 2명 이상일 때만 노출한다. 같은 계정의 추천과 댓글은 점수에는 각각 반영하지만 참여자 최소 인원에서는 한 번만 센다. 반복 댓글은 한 번만 기여한다.
- 동점은 참여자 수, 사이트 게시 시각, id 내림차순으로 결정한다.
- 작성자 제외 기준은 Signal.submitted_by_id다. 등록자가 없는 자동 수집 글은 특정 계정을 작성자로 간주하지 않는다. reviewed_by_id만으로 작성자라고 추정하지 않는다.
- 삭제·숨김 댓글과 추천 취소로 제거된 행, 미래 시각의 반응은 제외한다. 댓글 수정 시각은 사용하지 않는다. 추천을 취소했다 다시 누르면 현재 남아 있는 새 추천의 생성 시각을 사용한다. 시간당 순증가율이나 이전 6시간 대비 가속도 모델은 아니다.
- 조회수와 외부 스타·조회·반응 수는 점수에 포함하지 않는다. 서로 다른 계정이 실제 서로 다른 사람인지 보증하는 부정행위 방지 시스템은 이번에 구현하지 않았다.

## 화면·API

- 기존 왼쪽 소식 / 오른쪽 커뮤니티 배치를 유지한다. 대표 글은 기존 선택 방식으로 독립 조회하고 정렬 탭으로 변경하지 않는다.
- 아래 목록만 최신·인기·지금 뜨는으로 전환한다. 대표 글은 exclude_id로 서버에서 제외한 후 집계·페이지 처리한다. 다른 공개 글이 조건에 없으면 안내를 표시한다.
- 홈에 추천·댓글 총수를 복원했다. 이 총수는 상세 화면과 같은 기존 집계다. 인기·지금 뜨는에서는 작성자 제외 등 순위 기준에 맞춘 추천자·댓글 참여자 수도 별도로 표시한다. 총 댓글 수와 순위 기여자 수는 같지 않을 수 있다.
- GET /api/v1/signals/의 sort에 popular, trending을 추가하고 exclude_id 양의 정수를 지원한다. ranking_recommendations, ranking_commenters, ranking_participants, ranking_score는 해당 순위 계산 결과이며 DB 저장 필드가 아니다.
- 공개 상태 필터·카테고리·검색·전체 개수·페이지 처리는 순위 쿼리에서도 유지한다. 미공개 글을 공개 목록에 포함하지 않는다.
- 지금 뜨는은 화면에서 60초마다 재조회한다. 홈 목록 복귀 시 재조회하며, 상세의 추천·댓글 변경은 홈 캐시도 무효화한다.
- 기존 추천·댓글 created_at을 사용한다. 이번 순위 작업에는 신규 DB 컬럼·마이그레이션이 없다. 이전 본문 기능의 202609090001 마이그레이션은 운영 배포 시 여전히 필요하다.
